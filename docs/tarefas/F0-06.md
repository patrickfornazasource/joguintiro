## Objetivo

Bots conseguem 'ver' o jogo: abrir no navegador sem tela, tirar foto e detectar erros.

## Contexto

Playwright e Chromium já existem no ambiente dos bots: usar `require('playwright')`/import sem instalar navegador. Em outro ambiente, `npx playwright install chromium`.

## Passo a passo

1. Adicionar `playwright` como dev (mesma versão principal do ambiente, se existir).
2. Criar `scripts/shot.js`: faz build, sobe `vite preview` numa porta livre, abre a página em 1280x720, espera `window.__READY === true` (ou 10 s), salva `artifacts/shot.png`, encerra tudo.
3. Em `src/main.js`, definir `window.__READY = true` após o primeiro quadro renderizado.
4. Falhar (código de saída 1) se houver qualquer erro no console ou exceção na página, listando os erros.
5. Aceitar `--url-params` para abrir com parâmetros (ex.: `?mapa=treino`) e `--out` para o nome do arquivo.
6. Script `shot` no package.json.
