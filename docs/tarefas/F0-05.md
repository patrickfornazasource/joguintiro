# F0-05: Testes automáticos de lógica

| Campo | Valor |
|---|---|
| Fase | F0 (Fundação) |
| Depende de | [F0-04](F0-04.md) |
| Tamanho | P (P = até 1 sessão curta, M = 1 sessão, G = pode precisar de 2) |
| Tipo | teste |

## Objetivo

Ter `npm test` funcionando para os bots provarem que a física e as regras estão certas.

## Contexto

Usar o executor nativo do Node (`node --test`), sem bibliotecas extras.

## Passo a passo

1. Script `test`: `node --test tests/`.
2. Criar `tests/math.test.js` cobrindo todas as funções de `shared/math.js`.
3. Criar `tests/constants.test.js`: verifica que os objetos estão congelados e que todos os números são finitos e positivos onde fizer sentido.
4. Criar `tests/README.md` curto: como escrever um teste novo, convenção `nome.test.js`.

## Arquivos previstos

- `package.json`
- `tests/math.test.js`
- `tests/constants.test.js`
- `tests/README.md`

## Pronto quando

- [ ] `npm test` passa.
- [ ] Quebrar de propósito uma função faz o teste falhar (verificar e desfazer).
- [ ] `npm test` e `npm run build` passam (quando já existirem).
- [ ] Nenhum número de balanceamento fora de `shared/constants.js`.

## Como verificar

```bash
npm test
```
