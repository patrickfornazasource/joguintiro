## Objetivo

Ter o projeto rodando no navegador com uma cena 3D mínima.

## Contexto

Primeira tarefa de código. Repositório só tem documentação. Stack definida: Vite + Three.js no cliente, Node.js 22 com módulos ES (`"type": "module"`).

## Passo a passo

1. Criar `package.json` com `three` (dependência) e `vite` (dev). Scripts: `client` (vite --host), `build` (vite build).
2. Criar `.gitignore` com `node_modules/`, `dist/`, `artifacts/`, `.env`.
3. Criar `index.html` na raiz com `<canvas>` em tela cheia e `<script type="module" src="/src/main.js">`. Título: LUZ NEGRA.
4. Criar `src/main.js`: `WebGLRenderer` com antialias, `PerspectiveCamera` (FOV 90), cena com chão cinza 40x40, um cubo, `HemisphereLight` + `DirectionalLight`. Redimensionar com a janela.
5. Criar pastas vazias com `.gitkeep`: `shared/`, `server/`, `tests/`, `scripts/`.
6. Criar `vite.config.js` mínimo (porta 5173).
