## Objetivo

Pisar numa plataforma de salto lança o jogador para cima (e opcionalmente numa direção).

## Contexto

Bloco tipo `pad` com campo opcional `launch: {x,y,z}`; sem campo, lança só para cima.

## Passo a passo

1. Constante: `padSpeed: 17`.
2. Ao pousar num `pad`: `vel = launch` (ou `vel.y = padSpeed` mantendo horizontal). Recarrega pulo duplo.
3. Evento `pad`.
4. Adicionar 2 plataformas ao sandbox (uma vertical, uma direcional até uma plataforma alta).
5. Testes: pousar no pad lança; pad direcional chega à plataforma alvo na simulação.
