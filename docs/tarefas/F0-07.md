## Objetivo

Todo PR roda testes, build e captura de tela automaticamente.

## Contexto

Garante que nenhum bot entregue algo quebrado.

## Passo a passo

1. Criar `.github/workflows/ci.yml`: em `pull_request` e `push` no `main`. Node 22, `npm ci`, `npm test`, `npm run build`.
2. Job separado: instalar Chromium do Playwright, rodar `npm run shot` e publicar `artifacts/` como artefato do workflow.
3. Cache de dependências npm.

## Arquivos previstos

- `.github/workflows/ci.yml`

## Pronto quando

- [ ] O PR desta tarefa mostra os checks verdes.
- [ ] A captura aparece como artefato baixável.
- [ ] `npm test` e `npm run build` passam (quando já existirem).
- [ ] Nenhum número de balanceamento fora de `shared/constants.js`.
