# F0-03: Comando único para rodar tudo

## Objetivo

O dono do projeto roda o jogo inteiro com um comando só.

## Contexto

O dono não programa. Rodar o projeto precisa ser trivial.

## Passo a passo

1. Adicionar `concurrently` (dev).
2. Script `dev` que roda `server` e `client` juntos, com nomes e cores.
3. Criar seção **Como rodar no seu computador** no `README.md`: instalar Node.js (link oficial nodejs.org, versão LTS), baixar o projeto, `npm install`, `npm run dev`, abrir o endereço. Passos numerados, sem jargão.
4. Atualizar a seção Status do README.

## Arquivos previstos

- `package.json`
- `README.md`

## Pronto quando

- [ ] `npm run dev` sobe cliente e servidor juntos; Ctrl+C derruba os dois.
- [ ] README explica o passo a passo para alguém que nunca programou.
- [ ] `npm test` e `npm run build` passam (quando já existirem).
- [ ] Nenhum número de balanceamento fora de `shared/constants.js`.

```bash
npm run dev (verificar manualmente por 5 s e encerrar)
```
