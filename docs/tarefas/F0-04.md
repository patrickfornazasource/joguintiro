# F0-04: Pasta shared e constantes centralizadas

## Objetivo

Criar o lugar único para todos os números de balanceamento e o código compartilhado entre cliente e servidor.

## Contexto

Regra do projeto: números de balanceamento só em `shared/constants.js`; código de `shared/` é puro (sem Three.js, sem DOM).

## Passo a passo

1. Criar `shared/constants.js` exportando objetos congelados (`Object.freeze`): `PHYSICS` (passo fixo 1/120), `PLAYER` (raio 0,35; altura 1,8; altura agachado 1,1; olho 1,6; olho agachado 0,95; vida 100), `MOVE` (vazio por enquanto, com comentário apontando F1), `NET` (taxa 20 Hz).
2. Criar `shared/math.js` com vetores 3D simples em objetos `{x,y,z}`: `v3`, `add`, `sub`, `scale`, `dot`, `len`, `lenXZ`, `normalize`, `copy`. Sem classes, sem Three.js.
3. Importar `shared/constants.js` em `src/main.js` e em `server/index.js` (prova que funciona nos dois lados).
4. Cada constante com comentário curto: o que é e a unidade (m, m/s, s).

## Arquivos previstos

- `shared/constants.js`
- `shared/math.js`
- `src/main.js`
- `server/index.js`

## Pronto quando

- [ ] Cliente e servidor importam `shared/` sem erro.
- [ ] `shared/` não importa nada de `three` nem usa `window`/`document`.
- [ ] `npm test` e `npm run build` passam (quando já existirem).
- [ ] Nenhum número de balanceamento fora de `shared/constants.js`.

## Como verificar

```bash
npm run build
node -e "import('./shared/constants.js').then(m=>console.log(Object.keys(m)))"
```
