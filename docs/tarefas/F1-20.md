# F1-20: Painel de ajuste ao vivo (F4)

| Campo | Valor |
|---|---|
| Fase | F1 (Movimento) |
| Depende de | [F1-18](F1-18.md) |
| Tamanho | M (P = até 1 sessão curta, M = 1 sessão, G = pode precisar de 2) |
| Tipo | ferramenta |

## Objetivo

O dono ajusta os números do movimento durante o teste, sem programar, e devolve os valores.

## Contexto

Essencial para o Teste humano #1: o dono não edita código, então ajusta controles deslizantes e copia o resultado.

## Passo a passo

1. Adicionar `lil-gui` (dev ou dependência leve).
2. Tecla F4 abre um painel com todos os valores de `MOVE` agrupados (Chão, Pulo, Ar, Deslize, Parede, Slam, Dash, Plataformas, Corrimão), com faixas razoáveis (0,25x a 3x do padrão).
3. Para funcionar, `stepPlayer` lê de um objeto de configuração injetável (padrão = `MOVE` congelado; no modo ajuste, uma cópia editável). A física continua pura.
4. Botões: **Restaurar padrão**, **Copiar valores** (gera texto JSON e copia para a área de transferência), **Salvar neste navegador**.
5. Só disponível com `?ajuste=1` (não aparece para jogadores comuns).
6. Instruções no README: como abrir, ajustar e mandar os valores.
