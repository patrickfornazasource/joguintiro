# F1-01: Formato de mapa e mapa cinza inicial

## Objetivo

Definir como um mapa é descrito em dados e desenhá-lo em cinza.

## Contexto

Mapas da Fase 1 são caixas alinhadas aos eixos (AABB). Tipos de bloco: `solid`, `wallrun` (parede de corrida, marcação visível), `pad` (plataforma de salto), `rail` (corrimão), `uv` (Tinta UV, reservado para F4).

## Passo a passo

1. Criar `shared/maps/format.js`: função `box(cx,cy,cz, sx,sy,sz, tipo='solid', extra={})` que devolve `{min,max,type,...}`; `validateMap(map)` (sem caixas invertidas, tipos conhecidos, pelo menos 1 ponto de nascimento).
2. Mapa é objeto `{ id, name, boxes:[], spawns:[{x,y,z,yaw}] }`.
3. Criar `shared/maps/sandbox.js`: chão 60x60, 4 paredes externas, alguns blocos e uma escada simples.
4. Criar `src/world/mapRenderer.js`: cria malhas cinza; cor por tipo (`wallrun` com faixa ciano na borda, `pad` verde, `rail` laranja); contorno com `EdgesGeometry` para leitura de forma.
5. Escolher mapa por parâmetro de URL `?mapa=sandbox` (padrão sandbox).
6. Testes: `validateMap` aceita o sandbox e rejeita mapas inválidos.
