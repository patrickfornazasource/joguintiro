# F0-10: Painel de depuração (F3)

| Campo | Valor |
|---|---|
| Fase | F0 (Fundação) |
| Depende de | [F0-09](F0-09.md) |
| Tamanho | P (P = até 1 sessão curta, M = 1 sessão, G = pode precisar de 2) |
| Tipo | código |

## Objetivo

Tecla F3 mostra FPS, passos por segundo, posição, velocidade e estado do jogador.

## Contexto

Ferramenta para os bots e para o dono relatarem problemas ('o painel dizia X').

## Passo a passo

1. Criar `src/ui/debug.js`: div sobreposta, fonte monoespaçada, atualizada 4x por segundo.
2. API `debug.set(chave, valor)` para qualquer módulo publicar informação.
3. Mostrar por padrão: FPS, passos/s, contagem de chamadas de desenho (`renderer.info`).
4. F3 liga e desliga; lembrar a escolha no `localStorage` (com try/catch).

## Arquivos previstos

- `src/ui/debug.js`
- `src/main.js`
